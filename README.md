# Python Task 2 – BMI Calculator (Beginner)

## Description
A simple command-line BMI calculator.  
It takes weight and height, calculates BMI, and shows the category.

## Features
- Input validation (only positive numbers allowed)
- BMI calculation
- Category: Underweight, Normal, Overweight, Obese

## How to Run

1. Install Python 3.
2. Open terminal in this folder.
3. Run:

```bash
python bmi_calculator.py
```

4. Enter weight (kg) and height (m) when asked.
